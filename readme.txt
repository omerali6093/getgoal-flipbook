A smooth, 3D page-flip showcase flipbook powered by StPageFlip and GSAP.

== Description ==

GETGOAL 3D Flipbook delivers an interactive, 3D flipbook showcase designed for hero sections and portfolio presentations.

Features:
* Full interactive 3D page-turn physics with soft paper curvature
* Supports high-resolution images and embedded autoplay videos
* Bottom navigation bar with Previous, Next, Page Indicator (e.g. 1 / 18), and Fullscreen mode
* Touch swipe and arrow key navigation
* Responsive layout tailored for desktop, tablets, and mobile screens
* Automatic full-width container handling for Elementor and standard themes

== Installation ==

1. Upload the `getgoal-flipbook` folder to `/wp-content/plugins/` (or upload `getgoal-flipbook.zip` via WordPress Admin > Plugins > Add New > Upload Plugin).
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Place the shortcode `[getgoal_flipbook]` on any page or in your Hero Section.

== Shortcode Usage ==

Standard usage:
`[getgoal_flipbook]`

Custom max width:
`[getgoal_flipbook width="1400"]`
